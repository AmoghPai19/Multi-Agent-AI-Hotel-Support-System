# Graph Entrypoint Contract

## Purpose

This document defines the official entry point for the LangGraph orchestration layer. All backend services must use this contract when invoking the graph.

---

## Graph Object

```python
hotel_support_graph
```

This is the single compiled LangGraph instance exposed by `graph.py`.

---

## Invocation

The backend must invoke the graph asynchronously using:

```python
result = await hotel_support_graph.ainvoke(
    {
        "user_message": user_message,
        "guest_id": guest_id
    }
)
```

The graph must not be invoked directly by any agent. Only the FastAPI backend is responsible for calling the graph.

---

## Input Contract

The graph accepts the following initial state:

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| user_message | string | Yes | Guest's message |
| guest_id | string | Yes | Authenticated guest identifier |

No other fields should be provided during graph invocation.

---

## Output Contract

The graph returns the final `HotelSupportState`.

The returned state may contain:

| Field | Description |
|--------|-------------|
| intent | Classified guest intent |
| draft_response | Response generated by Conversation Agent |
| reservation_data | Reservation details (if applicable) |
| compliance_status | Compliance validation result |

---

## Execution Model

- Asynchronous execution (`ainvoke`)
- One request produces one final state
- No streaming in Phase 1
- Streaming support may be added in a future version without changing the graph interface
